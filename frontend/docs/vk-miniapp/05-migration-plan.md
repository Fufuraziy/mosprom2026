# План переделки в мини-приложение

Порядок выбран так, чтобы после каждого этапа приложение собиралось и работало, и этап можно было
закоммитить отдельно. Карта экранов — `03-screen-map.md`, код-заготовки — `02-vkui-router-cheatsheet.md`.

## Этап 0. Решения (приняты 24.10.2026)

1. Навигация — **вариант А**: нижний Tabbar «Квест / Награды / Крафти / Профиль».
2. **Тёмная тема — сразу** (этап 8 обязателен, цвета наших компонентов — только через токены или CSS-переменные).
3. **Только мини-приложение ВК.** Отдельный сайт-версию игры не делаем и не показываем. В браузере открывается
   то же мини-приложение (для разработки и проверки). **Панель HR** — отдельная веб-страница для сотрудников (вне мини-приложения). **Симулятор бота** остаётся,
   только если бэкенд не успеет настоящего бота; если бот живой — убрать.

## Этап 2. Роутер и панели-обёртки (быстрый результат)

- [ ] `routes.js` с путями из карты экранов. Сначала крупно: `/`, `/locker`, `/hub`, `/station/:id`, `/capsule`, `/rewards`.
- [ ] Каждый текущий экран обернуть в `<Panel>` + `<PanelHeader>`; `Header`, `Footer` и framer-motion
  `AnimatePresence` между экранами в режиме мини-приложения убрать — переходы делает `View`.
- [ ] `actions.go(screen, id)` заменить на `navigator.push(path)`. Источник правды для «где я» — роутер,
  в `GameContext` остаются только игровые данные. Телеметрию `navigate` слать из `router.subscribe`.
- [ ] Первая панель — `useEnableSwipeBack()`; на остальных `PanelHeaderBack` с учётом `useFirstPageCheck()`.
- [ ] Убрать `window.scrollTo` при смене экрана (VKUI сам хранит прокрутку панелей).
- [ ] Проверить Android «Назад» и свайп iOS: на каждом экране должно возвращать на предыдущий.

- [ ] Адаптер `storage.js`: внутри ВК — `VKWebAppStorageSet/Get`, вне ВК — localStorage.

## Риски и как их обойти

| Риск | Что делать |
|---|---|
| Tailwind preflight сбрасывает стили `button`, `img`, `h1` и может зацепить VKUI | VKUI стилизует классами — обычно они сильнее preflight. Если что-то поедет: `corePlugins.preflight = false` и точечный reset только внутри наших игровых контейнеров |
| Глобальные стили `body` и `#root` в `index.css` (фон, шрифт, `min-h-screen`) ломают `AppRoot` | В режиме мини-приложения фон и шрифт задаёт VKUI; наши стили — только внутри панелей |
| framer-motion и анимации VKUI сразу | Анимацию перехода между экранами отдаём `View`; framer оставляем внутри мини-игр |
| `fixed` и `100vh` в WebView (клавиатура, полоска «домой») | `Box position="sticky"`, `dvh`, модалки VKUI вместо своих `fixed inset-0` |
| VK Storage: лимит размера и числа вызовов | Разбить по ключам, debounce, оставлять localStorage как кэш |
| Тестирование на телефоне без VK Tunnel (недоступен с 02.10.2025) | 1) браузер `?vk_frame=1` + режим устройства в DevTools; 2) режим разработки с `http://localhost:5173` — только для веб-версии vk.com на том же компьютере; 3) `npm run deploy` на хостинг ВК для телефона; 4) eruda — консоль на телефоне |
| iOS без модерации открывает приложение в m.vk.com с элементами браузера | Для демо жюри показывать на Android или в браузере; для iOS — модерация платформы iOS и Company name |
| Большой бандл (фото, шрифты) — медленный первый запуск | `React.lazy` для станций и HR, сжать фото, оставить 2–3 начертания Montserrat |
| «Розыгрыш» как конкурс (п. 2.1.2) | Для хакатона ок; для реальной публикации согласовать или назвать «обмен баллов» |
