# Карта экранов: сайт → мини-приложение

Состояние кода на 24.10.2026, ветка `frontend`, коммит `9df0162`.

## Как устроено сейчас

`App.jsx` переключает экраны через `state.screen` в `GameContext`: `home | locker | hub | station | finale`.
Переход — `actions.go(screen, stationId)` и плавная смена через framer-motion. Адреса нет, истории нет,
поэтому «Назад» на Android закрывает приложение. Прогресс хранится в localStorage `ochakovo1978_game_v1`.

| Сейчас | Что это | Проблема для мини-приложения |
|---|---|---|
| `Header` | Липкая шапка: логотип → на главную, баллы, вкладки «Игра / ВК-бот / HR», кнопка рамки телефона | Правый угол занят капсулой ВК; это шапка сайта, а не `PanelHeader` экрана |
| `Home` | Длинный лендинг из 7 секций (герой, цифры, лента 1978–2000+, «5 причин» с якорем `#why`, ценности, 4 станции, призыв) | Прокрутка с якорями — паттерн сайта |
| `Locker` | Этап 0: выбор СИЗ, проверка | Нормальный отдельный экран |
| `Hub` | Карта 4 станций, галочка «Демо-ускорение» | Нормальный экран |
| `StationShell` + станции | Внутренние шаги (`step` 0–3: игра → игра 2 → квиз → награда), ссылка «← Карта станций» | Шаги не в истории, «назад» не возвращает на шаг |
| `Finale` | `view` = capsule / rewards; внутри rewards липкие вкладки (вердикт+калькулятор, мерч, анкета или первый день) и подвал (История, HR, «Пройти заново» через `window.confirm`) | Вкладки сайта, системный confirm, ссылка на HR |
| `MascotChat` | Плавающая кнопка справа снизу + выезжающий чат | Будет конфликтовать с Tabbar и безопасной зоной снизу |
| `Toasts` | Свои всплывашки сверху по центру | В ВК это `Snackbar` |
| `Footer` | Дисклеймер 18+, статус API | В мини-приложениях подвала нет |
| `StoryShare` | Модалка превью Истории | → `ModalPage` |
| `PhoneFrame`, `VkMiniAppBar` | Рамка телефона с фейковой капсулой ВК (для показа в браузере) | Внутри ВК не нужна; в браузере — главный способ показать мини-приложение жюри |
| `BotScreen`, `HRPanel`, `Dossier`, `InviteModal` | Режимы для жюри | Не часть мини-приложения: внутри ВК уже скрыты |

Места, которые надо поправить в любом случае:
- `window.confirm` — Finale.jsx;
- `window.scrollTo` при смене экрана — GameContext ×3, Finale, MascotChat, BotScreen;
- `scrollIntoView` — Home;
- `100vh` — Capsule, MascotChat, PhoneFrame;
- `fixed inset` — MascotChat, StoryShare, Dossier, InviteModal;
- `sticky top-[62px]` — Finale, Header.

## Предлагаемая структура (вариант А — рекомендую)

Разделы на нижнем Tabbar, внутри каждого — стек панелей. На время игры на станции и ввода кода Tabbar скрыт,
чтобы ничего не отвлекало, как в полноэкранном режиме игры.

```
Root "root"
 └─ Epic (activeStory = view)
     ├─ View "quest"      — вкладка «Квест»      (Icon28GameOutline)
     ├─ View "rewards"    — вкладка «Награды»    (Icon28GiftOutline, indicator — «новое» после капсулы)
     ├─ View "mascot"     — вкладка «Крафти»     (Icon28MessageOutline)
     └─ View "profile"    — вкладка «Профиль»    (Icon28UserCircleOutline)
Модалки (ModalRoot): age_gate, story_share, ppe_info, station_intro?, code_digit
Попауты: Alert (сброс, выход со станции), ScreenSpinner (старт, ожидание ИИ)
```

### Маршруты

| Путь | View / панель | Откуда берём содержимое | Tabbar | Заметки |
|---|---|---|---|---|
| `/` | quest / `home` | Герой + 3–4 карточки из Home (капсула, «5 причин», ценности, маршрут) | да | Первый экран: `useEnableSwipeBack()`. Карточки ведут на панели ниже |
| `/age` | модалка `age_gate` над `home` | Плашка 18+, дисклеймер из Footer | — | Правило 2.1.5. Показывать при первом запуске, флаг в VK Storage |
| `/story` | quest / `story` | Лента 1978–2000+ из Home | да | Или нативный `VKWebAppShowSlidesSheet` (до 10 слайдов, картинки 1,5:1, ≥ 832×555, ≤ 500 КБ) |
| `/why` | quest / `why` | «5 причин» из Home | да | +20 за карточку остаётся; карточка → `ModalCard` или горизонтальный `Gallery` |
| `/values` | quest / `values` | Ценности бренда | да | Можно объединить с `/why` |
| `/locker` | quest / `locker` | Locker | нет | Этап 0. Описание предмета СИЗ → `ModalCard` |
| `/hub` | quest / `hub` | Hub | да | Карта станций: `CardGrid` + `ContentCard`; «Демо-ускорение» → в Профиль |
| `/station/:id` | quest / `station_intro` | Шапка StationShell (фото, роль, зарплата, подсказка Крафти) | нет | Кнопка «Начать» внизу (`Box position="sticky"`) |
| `/station/:id/play/:step` | quest / `station_play` | Мини-игры станции: шаг 1, шаг 2 | нет | Каждый шаг — запись в истории. Уход назад посреди игры → `useBlocker` + Alert «Выйти со станции?» |
| `/station/:id/quiz` | quest / `station_quiz` | `Quiz` из StationKit | нет | |
| `/station/:id/done` | quest / `station_done` | `StationReward` + цифра кода | нет | Кнопка «На карту» делает `replace('/hub')`, чтобы «назад» не вёл в пройденную игру |
| `/capsule` | quest / `capsule` | Capsule (ввод 1978, формула) | нет | Доступен после 4 станций, иначе `Placeholder` «Собери 4 цифры» |
| `/rewards` | rewards / `verdict` | AIVerdict: архетип, 5 компетенций | да | До капсулы — `Placeholder` с прогрессом и кнопкой «К станциям». Ожидание ИИ — `Skeleton` |
| `/rewards/vacancies` | rewards / `vacancies` | Мэтч вакансий из вердикта | да | Список `RichCell` |
| `/rewards/salary` | rewards / `salary` | SalaryCalculator | да | Переключатели → `SimpleCell` + `Switch`; итог в sticky-блоке снизу |
| `/rewards/merch` | rewards / `merch` | MerchShop | да | Подтверждение покупки билета → `ModalCard` |
| `/rewards/apply` | rewards / `apply` | CandidateForm | нет | `FormLayoutGroup`, `FormItem`, `Input`, `DateInput`, `Select`, `Checkbox` согласия. Кнопка «Заполнить из ВК» с пояснением цели (1.1.2) |
| `/rewards/applied` | rewards / `applied` | Submitted + FirstDayGuide | да | После отправки — `replace` сюда, чтобы «назад» не возвращал в форму |
| `/mascot` | mascot / `chat` | MascotChat | да | Поле ввода — `WriteBar` над Tabbar; быстрые темы — `Chip`/`HorizontalScroll` |
| `/profile` | profile / `profile` | Баллы, билеты, архетип, статус анкеты | да | «Поделиться в Истории» → модалка `story_share`; «Пройти заново» → Alert |
| `/profile/about` | profile / `about` | Дисклеймеры из Footer, документы, поддержка, контакты | да | Правила 1.1.4, 2.4.1, 2.4.2; «Удалить мои данные» (1.1.10) |

Баллы: `PanelHeaderContent subtitle="1 250 баллов"` на игровых экранах и крупно в Профиле.
Анимацию начисления очков оставить в Snackbar: «+100 баллов».

### Что остаётся нашим (брендовым) внутри панелей

- Игровые поля всех станций: титрование, рефрактометр, пульт инженерии, линия розлива, ТТН, веер Pantone, Mirapolis.
- Иллюстрации: Крафти, СИЗ, капсула, рваная бумага, `REC`, квадратные модули, пиктограммы ОЧАКОВО.
- Крупные заголовки Montserrat в героях экранов.

Каркас — шапка, вкладки, списки, формы, модалки, уведомления, загрузка — берём из VKUI (правило 3.3.1).

### Вариант Б — без Tabbar

Один `View` со стеком: home → locker → hub → station… → capsule → rewards…; Крафти — шторка `ModalPage`,
Профиль — из кнопки в шапке слева. Проще в переделке, но меньше похоже на приложение и неудобно
возвращаться к наградам. Подходит, если времени совсем мало.

## Браузер (демо для жюри) и ВК

| Где открыто | Что показываем |
|---|---|
| Внутри ВК (`vk_app_id` + `sign` или `bridge.isWebView()`) | Только мини-приложение на VKUI, без HR и бота (как сейчас) |
| Браузер, `?vk_frame=1` | То же мини-приложение. Это содержимое рамки телефона |
| Браузер, обычный адрес | Демо-стенд: вкладки «Мини-приложение» (рамка телефона с iframe `?vk_frame=1`), «ВК-бот», «Панель HR». HR и бот остаются на текущей вёрстке |

Решения, которые надо согласовать с Игорем: вариант А или Б; поддерживать ли тёмную тему сразу
или пока принудительно светлую (`ConfigProvider colorScheme="light"`); оставлять ли сайт-версию игры без рамки.
