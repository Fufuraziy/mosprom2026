## Модерация: процесс

- Заявка подаётся в разделе «Модерация» панели управления: нужно выбрать платформы (Mobile / Web), описать сценарии,
  дать тестовые данные. Минимум 3 дня; может быть бета-тестирование (старт по пн и чт в 18:00 МСК).
- Без модерации приложение работает по ссылке, но с предупреждением «непроверенное». На iOS оно откроется
  в m.vk.com с элементами браузера, а не в WebView.
- С момента подачи заявки до публикации новые функции добавлять нельзя.
- Для хакатона модерация не обязательна: состояние «Включено» в разделе «Размещение» даёт доступ всем по ссылке
  `https://vk.com/app<ID>`, а жюри можно добавить в тестировщики.

## Оформление в каталоге (из «Оформление»)

- Иконка 576×576 (JPG/PNG), иконка каталога 278×278, маленькая 150×150 (экран запуска, сообщения), фавикон 32×32 ≤ 50 КБ.
- Большой сниппет 1120×630 (публикация ссылки на стене). Скриншоты 600×1200, одного размера и ориентации.
- Баннеры после публикации в каталоге: 800×1068 (мобильный), 1050×630 (десктоп); краткое описание для баннера ≤ 48 символов.
- Экран запуска: иконка в формате Lottie, цвет фона, анимация. ВК советует настроить его под интерфейс приложения.
