# ОЧАКОВО: Секретный код 1978 — фронтенд

Геймифицированная платформа привлечения и пребординга стажёров «Очаково» (кейс хакатона «Открой#Моспром» 2026).
React 18 + Vite 5 + Tailwind CSS 3 + Framer Motion + Lucide React.

## Запуск

```bash
cd frontend
npm install          # после обновления: подтянет @vkontakte/vk-bridge
npm run dev          # http://localhost:5173
npm run build        # статическая сборка в dist/ (base: './', можно выкладывать куда угодно)
```

Бэкенд FastAPI ищется на `http://localhost:8000`. Другой адрес: `VITE_API_URL=https://api.example.ru npm run dev`.
**Бэкенд не обязателен**: без него всё работает на встроенном движке (`src/services/localEngine.js`), статус виден
точкой в шапке и плашкой в панели HR. Контракт для бэкенда: [`API_CONTRACT.md`](./API_CONTRACT.md).

## Что внутри

**Режим студента**
1. Главная: детективная завязка (капсула 1978 в ЛЭП), лента времени 1978–2000+, интерактив «5 причин: почему Очаково» (+20 за карточку, телеметрия `why_ochakovo_cards_viewed`).
2. Этап 0 «Раздевалка»: выбор СИЗ по правилам справочника студента, счётчик попыток `ppe_attempts`, +100 и карточка ценностей.
3. Четыре станции, на каждой мини-игра + исторический квиз + цифра кода:
   - Лаборатория: титрование до точки эквивалентности, рефрактометр ATAGO RX-7000i, дегустационный лист образцов №5–8 → **1**;
   - Инженерия: пульт-мнемосхема (абсорбер, вентиль МЭА, барботёр KMnO₄, SCHENK, чан ЛЭП) в реальном времени, обход → **9**;
   - Розлив и склад: линия SMI SK 500 P с HMI и светофором, отбраковка мятой тары, ТТН на экспортную паллету → **7**;
   - Дизайн и Mirapolis: веер Pantone для 3D-банки KERN, тест «Инструменты менеджмента» (SMART/SWOT/Исикава/5 почему) → **8**.
4. Финал: ввод кода 1978 и формула «Очаково», ИИ-вердикт (архетип, 5 компетенций, мэтч вакансий), калькулятор дохода (ночные, общежитие, питание; изменения уходят в телеметрию), билеты на розыгрыш мерча за баллы, анкета 18+ со всеми полями ТЗ, интерактивный справочник первого дня.
5. Плавающий маскот «Крафти» (ИИ-агент №1): FAQ по справочнику студента, логирует темы вопросов `asked_topics`.

**Панель HR**: KPI (конверсия, прогноз отсева 38% → 9%, средний возраст), воронка, блоки целевых групп,
темы вопросов маскоту, таблица 12 демо-кандидатов + живые анкеты с фильтрами, ИИ-досье (5 шкал, retention, график 2/2,
шпаргалка по темам, наставник, риски), «Связаться», «Экспорт в Mirapolis», CSV.

**Для жюри**: на карте станций есть галочка «Демо-ускорение» — появляется кнопка «Пропустить мини-игру».
Прогресс хранится в `localStorage`; «Пройти заново» в финале сбрасывает его.

## Экосистема «ВК-бот + VK Mini App + HR-дашборд»

В шапке три вкладки:
1. **VK Mini App · Игра** — сама игра. Кнопка с телефоном справа открывает предпросмотр в рамке телефона
   с верхней панелью мини-приложения ВК (тот же сайт в iframe с `?vk_frame=1`, прогресс общий).
2. **ВК-бот ОЧАКОВО** — симулятор сообщений сообщества: кнопки бота («Начать», «Запустить Mini App», общежитие, сессия…),
   свободные вопросы, сценарии пушей для жюри (брошенная игра, сезонный набор, экскурсия, розыгрыш).
3. **Панель HR** — в таблице и досье кнопка «Написать через ВК-бота»: ИИ-приглашение по телеметрии кандидата,
   после «Отправить» оно появляется во вкладке «ВК-бот», а кнопки ответа кандидата работают.

`src/services/vk.js` — обёртка над `@vkontakte/vk-bridge`:
- `VKWebAppInit` при старте;
- «Заполнить анкету через ВКонтакте в 1 клик» — `VKWebAppGetUserInfo` (имя, фамилия, `bdate` → проверка 18+, город, `vk_user_id`);
- «Поделиться результатом в Истории ВК (+100)» — `VKWebAppShowStoryBox` с картинкой 1080×1920 в фирменном стиле;
- `VKWebAppAllowMessagesFromGroup` для подписки на бота.

Внутри ВК (в URL есть параметры запуска `vk_app_id` и `sign`) вкладки бота и HR скрыты и вызываются настоящие методы.
В обычном браузере кнопки не ломаются: подставляется демо-профиль (Алексей Смирнов, 21 год, 4 курс Росбиотеха)
с плашкой «Данные синхронизированы через VK ID», а история показывается превью.

Переменные окружения (`.env.local`):
```
VITE_API_URL=http://localhost:8000
VITE_VK_APP_ID=        # id мини-приложения — для ссылки в истории
VITE_VK_GROUP_ID=      # id сообщества — для подписки на сообщения бота
```

## Запуск внутри ВКонтакте

1. **Создать мини-приложение** (один раз, со своего аккаунта ВК): [dev.vk.com → Создать приложение](https://dev.vk.com/ru/admin/create-app)
   → тип «Мини-приложение» → название «ОЧАКОВО: Секретный код 1978» → категория. Запомнить **ID приложения**.
2. **Быстрый тест на компьютере** (без хостинга): `npm run dev`, затем в настройках приложения, раздел «Размещение»,
   включить режим разработки и указать адрес `http://localhost:5173` (для веб-версии и m.vk.com).
   Открыть `https://vk.com/app<ID>` в том же браузере — ВК загрузит игру с вашего компьютера.
3. **На телефон и для жюри** — бесплатный хостинг ВКонтакте:
   - вписать ID в `vk-hosting-config.json` (`"app_id"`) и в `.env.local` (`VITE_VK_APP_ID=<ID>`);
   - `npm run deploy` — сборка зальётся на хостинг ВК (утилита попросит подтвердить вход через ВКонтакте);
   - в «Размещении» выключить режим разработки, чтобы ВК открывал залитую версию;
   - открыть `https://vk.com/app<ID>` в мобильном приложении ВК.
   До модерации приложение видят администраторы и добавленные тестировщики — жюри можно добавить в тестировщики.
4. Внутри ВК игра сама понимает, что запущена во ВКонтакте (параметры запуска `vk_app_id` и `sign` в URL):
   вкладки «ВК-бот» и «Панель HR» скрыты, `VKWebAppGetUserInfo` подставляет настоящий профиль,
   истории публикуются через редактор историй (только в мобильном приложении ВК).

Бэкенд из ВК должен быть доступен по HTTPS (`VITE_API_URL=https://…`); пока его нет, игра работает на встроенном движке.

- **Цвета** (стр. 58 + Retail стр. 33–34): красный Pantone 199 `#D50032`, белый, тёмно-серый Cool Gray 10 `#626262`,
  серый Pantone 429 `#A2AAAD`, тёмно-красный Pantone 7621 `#AB2328`; дополнительно из Retail — зелёный `#84BD00`, голубой `#0086D6`.
  Токены: `tailwind.config.js` и `:root` в `src/index.css`.
- **Шрифт** (стр. 59): Proxima Nova — стоит первым в стеке; без лицензии используется открытая замена Montserrat
  с тем же приёмом контраста начертаний (Light/ExtraLight + ExtraBold, заголовки прописными).
- **Логотип**: векторные контуры из `ЛОГО БЕЗ КВАДРАТА/Лого_без квадрата.pdf` (`public/brand/ochakovo-logo-*.svg`,
  компоненты `Logo`, `LogoPlate`, `LogoSquare` в `src/components/ui.jsx`).
- **Пиктограммы** (стр. 50): 25 штук из `OCHAKOVO_pictograms.ai` → `public/brand/pictograms/*.svg` и `src/data/pictograms.js` (компонент `Picto`).
- **Паттерн** (стр. 52–55): из `OCHAKOVO_pattern_01.ai` в трёх цветовых сочетаниях (`public/brand/pattern-*.svg`),
  ставится отдельной полосой, не перекрывая текст.
- **Квадратные модули и заливки** (стр. 56–57): мозаика на главном экране, красные плашки и заливки.
- **Написание бренда** (стр. 61): ОЧАКОВО прописными без кавычек; юр. лицо — АО МПБК «ОЧАКОВО».
- **Платформа бренда** («Призвание»): «Натуральные — значит настоящие», миссия «Во благо людей. На благо страны.»,
  пять ценностей и характер бренда — блок на главной.

Из видеоролика «Процесс создания нового вкуса» оставлены акценты: рваная бумага на фото и плашка `● REC`.
Фото — кадры из вакансионных роликов и каталога (`public/brand/photos/`).
