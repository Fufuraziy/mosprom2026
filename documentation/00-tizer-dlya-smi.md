# Краткое описание решения (тизер, в том числе для СМИ)

Мини-приложение ВКонтакте «ОЧАКОВО: Секретный код 1978» за 12–15 минут знакомит студентов и выпускников 18–26 лет с профессиями комбината и превращает интерес в анкету на практику.

**Краткое описание решения:**
Чтобы ОЧАКОВО знали не только по квасу, но и как работодателя, мы превратили историю компании и реальную работу в цехах в детективный квест. В 1978 году, перед Олимпиадой-80, в Лаборатории экспериментального пивоварения заложили «Капсулу Мастерства». Открыть её можно, только пройдя четыре профессии завода.
1. Игрок попадает в мини-приложение из ВК-бота сообщества или по QR-коду с листовки, подтверждает 18+ и в «раздевалке» выбирает нужные средства защиты.
2. На четырёх станциях он решает реальные задачи. Лаборант титрует и контролирует Brix на рефрактометре ATAGO. Машинист следит за давлением в абсорбере и разбирается с аварией МЭА. Оператор розлива ищет брак на линии SMI SK 500 P и заполняет накладную. Дизайнер подбирает палитру для банки KERN и проходит тест по инструментам менеджмента. Каждая станция даёт исторический факт, мини-квиз и одну цифру кода.
3. Весь путь ведёт ИИ-маскот Крафти: рассказывает легенду, подсказывает при ошибках и отвечает в чате на вопросы про общежитие, зарплату и сессию строго по базе знаний компании.
4. По поведению в мини-играх считается профиль: 5 компетенций, архетип, совпадение с вакансиями и прогноз удержания. Студент получает вердикт и калькулятор дохода с учётом общежития и столовой, меняет баллы на билеты розыгрыша мерча и отправляет анкету.
5. HR видит воронку и ИИ-досье кандидата с рекомендованным наставником, а персональное приглашение отправляет через ВК-бота одним кликом.

Дополнительно мы сделали концепцию HR-бренда «Я делаю натуральные напитки», капсульную коллекцию мерча, листовки с QR-кодами для вузов и ролик для VK Клипов.

**Технические особенности:** React, Vite, VKUI, VK Bridge, Tailwind CSS, Leaflet + OpenStreetMap, Python, FastAPI, SQLAlchemy, SQLite, LLM (OpenAI-совместимый API / Gemini) с детерминированным движком на базе знаний, VK Bots API (Long Poll / Callback), Docker, GitHub Actions и хостинг VK Mini Apps.

**Уникальность:** в найденных нами открытых источниках нет решения, которое объединяет в одной воронке ВКонтакте игровые симуляторы реального производства, поведенческую оценку кандидата, ИИ-наставника и возврат кандидата в диалог с HR. Отдельные части подхода известны, например:
1. Marriott, социальная игра My Marriott Hotel на Facebook для найма молодёжи 18–27 лет (2011): геймификация рекрутинга без оценки компетенций. [Restaurant Online](https://restaurantonline.co.uk/Article/2011/06/28/Marriott-uses-Facebook-game-to-aid-recruitment-among-millennials)
2. Frontiers in Psychology, Game-related assessments for personnel selection: A systematic review (2022): игровые задания как инструмент оценки при отборе персонала. [doi:10.3389/fpsyg.2022.952002](https://doi.org/10.3389/fpsyg.2022.952002)
3. FESCO, карьерный сайт talents.fesco.com для привлечения студентов на практики (2025): HR-бренд для молодёжи без игровой механики. [Ruward](https://ruward.ru/cases/8513/)
