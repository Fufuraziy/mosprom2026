# Фактический отчёт по проекту «ОЧАКОВО: Секретный код 1978»

Отчёт для подготовки финальной презентации хакатона «Открой#Моспром». Здесь только то, что есть в коде прямо сейчас: компоненты, константы, формулы, эндпоинты. У каждого утверждения указан файл, где его можно проверить.

Срез кода: ветка `design` (коммит `a095d79`) отведена от `main` на коммите `5e2abd8` (Merge PR #15) и добавляет маскота-сторителлера, мерч PURE CRAFT 1978 и Бренд-Кит. С тех пор `main` ушёл вперёд: карта переведена на OpenStreetMap и получила векторную схему (PR #17, `3303447`), добавлены `LICENSE` и правки CI для деплоя. Ветка `design` ещё не влита в `main` и не задеплоена. Всё из блока 5 (кроме цветов и шрифтов) и маскот-сторителлер из блока 3 появятся в мини-приложении во ВКонтакте только после слияния. Описание карты в блоке 3 взято из `main`, остальное из `design`.

## Что стоит знать перед слайдами

- Название везде одно: «Секретный код 1978» (интерфейс, `README.md`, ВК-бот, `Dockerfile`). Старое рабочее название «КРАФТ-КОД 1978» убрано.
- Без бэкенда всё работает офлайн. Игра, ответы Крафти, вердикт, анкета, панель HR и симулятор бота идут на встроенном движке в браузере (`frontend/src/services/localEngine.js`, `botEngine.js`). Цифры в панели HR при этом отличаются от тех, что даёт бэкенд (см. блок 4).
- Живой LLM и настоящий ВК-бот включаются только ключами в `backend/.env`. Без них отвечают детерминированные движки на базе знаний. Подробности в блоке 7.
- Несколько утверждений в корневом `README.md` расходятся с кодом. Они собраны в блоке 7, в разделе «Расхождения».
