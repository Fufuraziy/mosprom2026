# Передача бэкенд-агенту: «ОЧАКОВО: Секретный код 1978»

Документ для того, кто пишет FastAPI-бэкенд. Фронтенд готов и лежит в `frontend/`.
Точные форматы запросов и ответов описаны в [`frontend/API_CONTRACT.md`](frontend/API_CONTRACT.md). Ответы на вопросы бэкенда о формате аналитики, `telemetry.stations`, архетипах и `GET /api/candidates` лежат в конце этого файла. Если форма ответа отклоняется от контракта, фронт сглаживает её в `frontend/src/services/normalize.js`.
Здесь собраны контекст, приоритеты, подводные камни и то, что из контракта не видно.

## 1. Что за продукт

Экосистема привлечения студентов 18+ на практику в ОЧАКОВО. Путь такой: ВК-бот → VK Mini App (игра) → панель HR.

- Игра (VK Mini App): 4 станции-мини-игры, квизы, капсула «1978», ИИ-вердикт, калькулятор дохода, мерч за баллы, анкета 18+.
  Каждое действие игрока пишется в телеметрию, из неё строится профиль компетенций.
- ВК-бот сообщества «ОЧАКОВО: Карьера и практика»: отвечает на вопросы, запускает мини-приложение, шлёт пуши.
- Панель HR: воронка, кандидаты, ИИ-досье по телеметрии, персональное приглашение через бота.

Два ИИ-агента:
1. Маскот «Крафти» (агент №1): отвечает на вопросы про практику и классифицирует тему вопроса.
2. Рекомендатель (агент №2): архетип, мэтч вакансий, вердикт; плюс генерация приглашения от HR.

## 2. Главное про взаимодействие с фронтом

Фронт работает и без бэкенда. `frontend/src/services/api.js` при старте делает `GET /api/health`
(или `/health`). Если ответа нет за 1,5 с, всё считает встроенный движок `src/services/localEngine.js`
с теми же структурами данных. Для бэкенда из этого следует:

| Ситуация | Что сделает фронт |
|---|---|
| `/api/health` не ответил | весь сеанс в автономном режиме, перепроверка раз в 20 с |
| эндпоинт вернул 404 / 405 / 501 | тихо посчитает локально, удобно делать эндпоинты по одному |
| 5xx или таймаут | пометит бэкенд упавшим на 20 с и уйдёт в локальный режим |
| 400 / 422 | покажет ошибки пользователю (формат ниже), в локальный режим не уйдёт |
| ответ не той формы | возьмёт локальный результат (проверяет ключевые поля) |

Таймауты: у обычных запросов 3,5 с, у ИИ-эндпоинтов (`/api/mascot/chat`, `/api/recommendation`,
`/api/bot/message`, `/api/bot/invite-draft`) 15 с. Если LLM не успевает, фронт ответит шаблоном,
поэтому ставьте у LLM свой таймаут ~10 с и отдавайте шаблонный ответ сами.

Увидеть, что фронт нашёл бэкенд, можно по точке в шапке справа: зелёная значит онлайн; в панели HR плашка
«FastAPI онлайн · localhost:8000». Адрес меняется через `VITE_API_URL` в `frontend/.env.local`.

Ошибки валидации можно отдавать в любом из двух форматов:
```json
{"errors": {"birth_date": "В ОЧАКОВО принимают строго с 18 лет"}}
{"detail": [{"loc": ["body", "form", "birth_date"], "msg": "..."}]}
```
Ключ поля берётся из последнего элемента `loc`.

Общие правила: JSON, `snake_case`, id строками, даты в ISO 8601.

## 3. Приоритеты (что делать в каком порядке)

| # | Эндпоинт | Зачем | Без него |
|---|---|---|---|
| 1 | `GET /api/health` | фронт вообще начнёт ходить в бэкенд | всё локально |
| 2 | `POST /api/candidates` + `GET /api/candidates` | анкеты сохраняются на сервере, HR видит их с любого устройства | анкеты живут в localStorage одного браузера |
| 3 | `GET /api/analytics/summary` | цифры панели HR по реальным данным | см. п. 6 «Демо-данные» |
| 4 | `POST /api/telemetry`, `POST /api/sessions` | воронка (сколько открыли, начали, дошли) | воронка из констант |
| 5 | `POST /api/mascot/chat` | ИИ-ответы маскота | FAQ по ключевым словам |
| 6 | `POST /api/recommendation`, `POST /api/bot/invite-draft` | ИИ-вердикт и приглашение | шаблоны |
| 7 | `GET /api/candidates/{id}/dossier`, `POST …/mirapolis` | досье с сервера | досье считается на фронте |
| 8 | `POST /api/bot/*` + VK Callback API | настоящий ВК-бот | симулятор во вкладке «ВК-бот» |
| 9 | `POST /api/raffle/tickets` | учёт билетов розыгрыша | localStorage |

Для защиты нужен минимум 1–4. ИИ (5–6) сильнее всего впечатляет жюри.

## 4. Модель данных

### Кандидат (`POST /api/candidates`)

Тело запроса: `{ form, telemetry, points, session_id }`. Поля `form`:
`fio, phone, telegram, email, birth_date (YYYY-MM-DD), vacancy, readiness, university, study_level, specialty, consent, vk_user_id, vk_source`.

Серверная валидация обязательна. На фронте она тоже есть, но доверять ей нельзя:
- ФИО минимум из 2 слов;
- возраст ≥ 18 лет строго (требование кейса, слайд 6);
- хотя бы один контакт: `phone` / `telegram` / `email` / `vk_user_id`;
- `vacancy`, `readiness`, `university` заполнены; `consent === true` (152-ФЗ, храните факт и время согласия).

Ответ: объект кандидата плюс `id`, `created_at`, `is_live: true`.
`GET /api/candidates` должен отдавать и `telemetry` (как минимум `asked_topics`, `stations`, `calculator`,
`why_ochakovo_cards_viewed`, `ppe_attempts`, `quiz`), по ним фронт рисует столбцы таблицы и досье.
Производные поля (`age`, `competencies`, `archetype`, `retention_score`, `top_match`, `shift`) считать не нужно:
фронт пересчитывает их по `telemetry` для каждого кандидата из списка (ваши значения этих полей перезапишутся).
Поле `block` (`engineering | profile | line | free`) фронт возьмёт ваше, если оно есть.
Если нужен серверный скоринг, отдавайте его через `GET /api/candidates/{id}/dossier`, там фронт показывает ответ как есть.

### Телеметрия
Полный пример объекта `telemetry`: в `API_CONTRACT.md`. Поток событий `POST /api/telemetry`:
`session_open, navigate, points, why_ochakovo_cards_viewed, ppe_attempt, ppe_done, quiz_answer, station_done,
capsule_attempt, capsule_open, raffle_ticket, calculator, asked_topics, candidate_submitted,
vk_init, vk_autofill, vk_story_share, bot_message, bot_push, hr_bot_invite`.
Из этих событий строится воронка (п. 6). Сессия анонимна до отправки анкеты, связывайте по `session_id`.

### Скоринг (если будете считать на сервере)
Эталонная реализация: `frontend/src/services/localEngine.js`, функции `computeCompetencies`, `retentionScore`,
`vacancyMatches`, `archetypeFor`, `buildDossier`. Кратко:
- 5 компетенций 0–100: `safety` (попытки выбора СИЗ), `lab` (титрование + Brix), `speed` (брак на линии),
  `systems` (стабильность давления + реакция на аварию МЭА + обход), `lms` (тест Mirapolis + квизы);
- `retention_score` 25–97: база + средняя компетенция + открытые «5 причин» + использование калькулятора +
  готовность к ночным + готовность выйти; минус пропуски мини-игр в демо-режиме;
- мэтч вакансии = взвешенная сумма компетенций (веса в `data/content.js → VACANCIES`).
Формулы здесь эвристика для прототипа, после пилота их стоит откалибровать на реальном удержании.

## 5. ИИ-агенты: что ждёт фронт

### Маскот `POST /api/mascot/chat`
Вход: `{session_id, message, history: [{role, text}]}` (последние 8 реплик).
Выход: `{reply, topic, topic_label?, suggestions?}`. `topic` обязателен: по нему HR видит, что волнует кандидата. Список тем: `dorm, salary, session, military, schedule, contract, food, transport, uniform, mentor,
health, pass, practice_docs, brands, history, vacancies, other`.

База знаний: только факты из материалов кейса: `task/spravochnik_studenta_ochakovo.md`,
`task/usloviya_praktiki_ochakovo.md`, `history/history.md`. Готовые проверенные ответы по темам лежат в
массиве `FAQ` в `localEngine.js` (можно использовать как few-shot или RAG-документы).
Правила для системного промпта:
- суммы зарплат: «до вычета НДФЛ»; не выдумывать цифры, которых нет в материалах;
- работа и практика только с 18 лет; не рекламировать алкоголь (пивные бренды упоминаются только как история компании);
- бренд пишется ОЧАКОВО прописными без кавычек (брендбук, стр. 61); юрлицо называется АО МПБК «ОЧАКОВО»;
- не знаешь: отправь в отдел подбора: 8 800 100 77 77, доб. 1155.

### Рекомендация `POST /api/recommendation`
Вход: `{session_id, telemetry}`. Выход обязан содержать `archetype {id, name, tagline, icon}`,
`competencies`, `matches[] {id, title, dept, salary, block, match}`, `retention_score`, `verdict` (текст).
Без `archetype` и `matches` фронт возьмёт локальный расчёт. Архетипы и иконки: `ARCHETYPES` в `content.js`.

### Приглашение от HR `POST /api/bot/invite-draft`
Вход: `{candidate_id}`. Выход: `{text, based_on: [строки «ИИ учёл»], keyboard?}`.
Текст: на «ты», 500–700 символов: баллы, сильные стороны, архетип, мэтч, дата/место
(ул. Рябиновая, 44, Учебный центр, каб. 525), ответ на темы, которые кандидат спрашивал у маскота, имя наставника.
Эталонный шаблон: `inviteDraft()` в `frontend/src/services/botEngine.js`.

## 6. Демо-данные: договориться заранее

Во встроенном движке есть 12 вымышленных кандидатов и константы воронки (1 840 → 1 236 → … → 130).
Когда бэкенд онлайн:
- `GET /api/candidates`: фронт показывает только ваш список, вымышленные не подмешиваются;
- `GET /api/analytics/summary`: если эндпоинта нет (404), фронт посчитает аналитику локально, и в KPI
  окажутся вымышленные кандидаты и константная воронка, а в таблице, ваши реальные. Поэтому
  сделайте `analytics/summary`, считая воронку по событиям телеметрии.

Решение по демо пока не принято (обсуждается флаг `VITE_DEMO_DATA` на фронте). Если хотите демо-кандидатов
на защите: засейте их в БД из `frontend/src/data/seedCandidates.js` и помечайте `is_demo: true`.
Метрика «отсев на испытательном 38% → 9%» сейчас остаётся константой-прогнозом; если будете её считать, отдавайте
`probation_dropout: {current, forecast}`.

## 7. VK Mini App: что важно бэкенду

- Мини-приложение открывается ВКонтакте с параметрами запуска в URL: `vk_user_id, vk_app_id, vk_platform, vk_ref, sign, …`.
  Не доверяйте `vk_user_id` без проверки подписи. Алгоритм: взять все параметры, начинающиеся с `vk_`,
  отсортировать по ключу, собрать `key=value&…` (URL-кодирование), HMAC-SHA256 с защищённым ключом приложения,
  base64url без `=` → сравнить с `sign`. Фронт пока не передаёт строку запуска; если она нужна, договоримся о заголовке
  (например, `X-VK-Launch-Params: <location.search>`).
- `form.vk_source`: `vk` значит данные из `VKWebAppGetUserInfo`, `demo` значит демо-профиль в обычном браузере (не реальный человек).
- HTTPS обязателен. Мини-приложение живёт на хостинге ВК (https), браузер заблокирует запросы на `http://` как mixed content. С телефона `localhost:8000` недоступен в принципе. Для защиты нужен публичный
  HTTPS-адрес (деплой или туннель: cloudflared / ngrok).
- CORS: разрешите `http://localhost:5173`, `https://*.vk-apps.com` (хостинг ВК) и адрес, где будет выложен фронт.
  Методы `GET, POST, OPTIONS`, заголовок `Content-Type`.
- `vk_ref=story` приходит у тех, кто открыл приложение по кнопке из истории; учитывайте в воронке как канал.

### 7.1. Дополнение от 24.10: фронт переходит на настоящий VK Mini App (VKUI + роутер)

Подробности для фронта лежат в `frontend/docs/vk-miniapp/`. Бэкенда касается следующее:

- Строка запуска в заголовке. Фронт будет слать в каждом запросе `X-VK-Launch-Params: <window.location.search без ?>`
  (вне ВК заголовка нет). Подпись проверяется по алгоритму выше; ключ берётся из поля «Защищённый ключ» в настройках приложения.
  Эталон ВК на Python:
  ```python
  from base64 import b64encode; from hashlib import sha256; from hmac import HMAC, compare_digest
  from urllib.parse import parse_qsl, urlencode
  def is_valid(qs: str, secret: str) -> bool:
      q = dict(parse_qsl(qs, keep_blank_values=True))
      vk = sorted((k, v) for k, v in q.items() if k.startswith('vk_'))
      h = b64encode(HMAC(secret.encode(), urlencode(vk, doseq=True).encode(), sha256).digest()).decode()
      return compare_digest(q.get('sign', ''), h.rstrip('=').replace('+', '-').replace('/', '_'))
  ```
  Если подпись верна, `vk_user_id` можно доверять (привязывать сессию, анкету, удаление). Если подпись неверна или заголовка нет, работайте как с анонимом и не падайте.
- CORS: добавить заголовок `X-VK-Launch-Params` в `Access-Control-Allow-Headers`, иначе preflight отклонит запрос.
  Точный адрес хостинга ВК виден после первого `npm run deploy`. Разрешать по шаблону `https://*.vk-apps.com`.
- Публичный HTTPS нужен уже для тестов на телефоне: VK Tunnel не работает с 02.10.2025, а `localhost` с телефона недоступен. Нужен деплой бэкенда или туннель (cloudflared / ngrok), адрес передадим во фронт через `VITE_API_URL`.
- Удаление данных (правило ВК 1.1.10): нужен эндпоинт `DELETE /api/candidates/me`, который удаляет анкету и телеметрию
  пользователя из проверенного `vk_user_id`. Ответ `{ok: true}`. Фронт добавит кнопку «Удалить мои данные» в Профиль.
- Согласие на ПДн (1.1.2, 1.1.4): анкета уже присылает `consent: true`. Сохраняйте время согласия и версию текста
  (`consent_at`, `consent_version`); ссылки на политику и соглашение укажем в настройках приложения ВК.
- Новые адреса экранов (hash-роутер) для ссылок бота и HR:
  `https://vk.com/app<ID>#/hub` (вернуться в игру), `#/rewards/apply` (анкета), `#/rewards` (результат), `#/` (начало).
  Знак `?` в прямой ссылке ВК не передаёт, остаётся только `#`. У кнопки клавиатуры `open_app` для этого есть поле `hash`
  (без `#`, например `"hash": "/hub"`).
- Пуши: массовые уведомления мини-приложения (`notifications.sendMessage`) доступны только приложениям из каталога,
  поэтому для хакатона остаётся один канал: сообщения сообщества через бота.
- Аналитика: в `POST /api/sessions` фронт добавит `vk_platform` и `vk_ref` из строки запуска, пригодится для воронки
  по каналам (история, бот, каталог) и платформам.
- Код капсулы (с 24.10): у каждой игры свой случайный 4-значный код (цифра N открывается на станции N).
  Фронт генерирует его сам и при старте новой игры шлёт `POST /api/sessions {session_id, target_code: ["5","8","3","2"], vk_platform, vk_ref}`.
  Бэкенд сохраняет этот код (или генерирует свой, если фронт не прислал) и возвращает `target_code`; фронт принимает код сервера,
  только пока ни одна цифра не открыта. Повторный вызов с тем же `session_id` возвращает уже сохранённый код.
  Для защиты от накрутки проверяйте на сервере `capsule_attempt` против `secret_code` сессии и наличие 4 событий `station_done`.
- Прогресс игры фронт хранит в VK Storage (синхронизируется между устройствами сам), отдельный эндпоинт для прогресса
  не нужен.

## 8. ВК-бот (если будете делать настоящего)

Фронт показывает симулятор, а настоящего бота делаете вы. Сейчас вся логика ответов и тексты лежат в
`frontend/src/services/botEngine.js` (`botRespond`, `pushMessage`, `inviteDraft`), и её стоит перенести на сервер,
чтобы симулятор и настоящий бот отвечали одинаково через `POST /api/bot/message`.

- Транспорт: VK Callback API (нужен публичный HTTPS-URL; на событие `confirmation` вернуть строку
  подтверждения из настроек сообщества) или Bots Long Poll API (не нужен публичный URL, проще для хакатона).
- Отправка: `messages.send` с токеном сообщества, обязательный `random_id` (идемпотентность).
- Клавиатура: `{"one_time": false, "buttons": [[{"action": {"type": "text", "label": "…", "payload": "{\"cmd\":\"dorm\"}"}, "color": "secondary"}]]}`.
  Payload-ы фронта: `start, open_app, continue, dorm, session, salary, vacancies, subscribe, stop, iv_yes, iv_question,
  iv_later, season_yes, excursion_yes`. Для «Запустить Mini App» у ВК есть кнопка типа `open_app` (`app_id`, `owner_id`, `label`).
- Писать первым можно только тем, кто разрешил сообщения сообщества (в мини-приложении для этого
  `VKWebAppAllowMessagesFromGroup`) или сам писал боту. `POST /api/bot/send` должен честно возвращать
  `delivered: false`, если писать нельзя.
- Сценарии пушей для демо: брошенная игра (по последнему событию телеметрии), старт сезонного набора, экскурсия,
  итоги розыгрыша. Тексты лежат в `pushMessage()`.

## 9. Как проверить связку

```bash
cd frontend && npm install && npm run dev        # http://localhost:5173
# бэкенд на http://localhost:8000, фронт подхватит его сам
```
1. Точка в шапке стала зелёной → `/api/health` отвечает.
2. Пройти игру (на карте станций есть «Демо-ускорение»), заполнить анкету → кандидат должен появиться в вашей БД и
   во вкладке «Панель HR» с меткой «новый».
3. Спросить маскота «а если сессия?» → в досье кандидата тема «Сессия и учёба».
4. В панели HR → иконка сообщения у кандидата → текст приглашения должен прийти с вашего `/api/bot/invite-draft`.
5. DevTools → Network: все запросы к `localhost:8000` без ошибок CORS.

По вопросам фронта пишите в этом репозитории, ветка `frontend`.
